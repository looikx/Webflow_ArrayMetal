05

What we deliberately change

These are implementation defects, not brand decisions. Reproducing them faithfully would be the wrong kind of fidelity. Each one is a change, so each needs sign-off.

1 · The Load Ratings embed is off-brand

.lr-* ships #1a1a2e navy, #c8a951 gold and #f5f5f0 cream — none of them brand tokens — plus Arial. On /load-ratings it reads as a different company's page.

Live today
AML100 — Safe working load
On brand
AML100 — Safe working load
→ Fix when porting the calculators to React (Phase 4).

2 · Body text is Arial

body sets font-family:Arial,sans-serif and nothing overrides it. The brand faces are applied class-by-class across 105 rules, so any element without a class — including CMS rich-text output — silently falls back to Arial.

Live — unclassed text

Hot-dip galvanized to ISO 1461, 3 m standard length.

Brand face set on :root

Hot-dip galvanized to ISO 1461, 3 m standard length.

→ Set the brand face once on :root. Never per-class.

3 · h5 is Alice Blue on white — 1.3 : 1

Effectively invisible anywhere outside a dark band. It works only where it was first authored.

Live
Nominal width 300 mm
Fixed
Nominal width 300 mm
→ Re-colour to --slate-grey, or scope Alice Blue to dark sections only.

4 · A border that never renders

.button-10, .button-11 and .nav-link.w--current all carry border:1px #17a651 — no border-style, so nothing draws. Copy-paste drift replicated across four rules.

→ Drop it. Green is not in the palette.

5 · No focus-visible styling anywhere

Keyboard users get Webflow's default #3898ec ring or nothing at all. On a catalogue with filter chips, configurators and enquiry forms this is a genuine usability failure, not a nicety.

→ 3 px --midnight-blue ring at 2 px offset on every interactive element. (Tab through this page to see it.)

6 · Section padding drift

59px, 60px, 65px, 80px, 110px for what is visually the same band. The 59 is a drag-error.

→ Collapse to a 3-step scale: 30 / 60 / 100.
06

The extension — five tokens can't build a catalogue

The current site is a brochure. It has no hover, focus, disabled, error or success colour, and one flat grey. A catalogue with filter chips, sortable SKU tables, validation and an enquiry list needs states. Nothing here is invented: the neutral ramp is the straight line between the two brand neutrals, extended in both directions.

07

The one thing that could break this

Font licensing

Maison Neue (Milieu Grotesque) and Halyard Display (Darden Studio) are paid, licensed webfonts. The current licence was bought for a Webflow-hosted site. Serving them from Vercel is a different host and possibly a different pageview tier.

OutcomeConsequence
Licence already covers self-hosting at our trafficRe-host five files. Zero visual change. Preferred
Licence needs upgradingA budget line. Still zero visual change
Licence cannot be extendedSubstitution — and the typographic identity changes

Fallbacks if substitution is forced: Maison Neue → Inter; Halyard Display → Jost. Any substitution gets a side-by-side review first — it is the single change here a customer would actually notice.

Owner: Kai. Blocks Phase 4. Tracked as Open Item 8 in the build plan.

Acceptance gate

The design system is done when all of these are true.

  • tokens.css exists in array-metal-web with all five brand values byte-identical to §1
  • Both typefaces load self-hosted, licence confirmed (§7)
  • <Section> <Container> <Button> <SiteHeader> <SectionHeader> implemented per §4
  • An existing arraymetal.com page, rebuilt on the new stack, sits beside the Webflow original and reads as the same site
  • Every §5 divergence either fixed or explicitly waived, in writing
  • Every interactive element has a visible :focus-visible state
  • No #3898ec and no .lr-* palette value anywhere in the new repo
  • Contrast checked at AA for every token pair actually used together
